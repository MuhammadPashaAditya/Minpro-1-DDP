Sistem Pendataan Barang Hilang dan Ditemukan
Deskripsi

Sistem Pendataan Barang Hilang dan Ditemukan adalah program Python sederhana yang digunakan untuk mengelola data barang yang hilang atau telah ditemukan.

Program ini menggunakan list sebagai tempat penyimpanan data sementara dan menyediakan empat operasi utama, yaitu menambahkan, menampilkan, mengubah, dan menghapus data.

Tujuan
Program ini dibuat untuk menerapkan konsep dasar pemrograman Python, khususnya:

* List
* While loop
* For loop
* Conditional statement
* Input dan output
* Validasi data
* Operasi CRUD

Fitur Program
1. Tambah Data Barang
2. Tampilkan Data Barang
3. Ubah Data Barang
4. Hapus Data Barang
5. Keluar dari program

Program juga memiliki validasi untuk mencegah kesalahan input, seperti:

* Menu yang tidak valid
* ID barang kosong
* ID barang yang sudah digunakan
* ID barang yang tidak ditemukan
* Nama barang kosong
* Lokasi kosong
* Pilihan status yang tidak valid
* Konfirmasi sebelum menghapus data

Struktur Data
Data disimpan menggunakan nested list dengan format:

```python
[ID Barang, Nama Barang, Lokasi, Status]
```

Contoh:
python
["B001", "Dompet hitam", "Kantin", "Belum ditemukan"]
